为什么要"听"而不是"看 IPA"

IPA 是参考，就像查一个外语词的字典条目——你不会盯着 /ˈʃɑːdənˌfrɔɪdə/ 去学发音，你听别人念三遍才学会。Pronounce 把系统 TTS 接到一行 CLI 上，让答案直接进耳朵，而不是停在纸面上的音标。

常见问题

为什么不直接看 YouTube 视频？

因为你得先搜对视频、取消静音、等加载、再倒回。say-it "Gemini 4 Carbon" 把读法连播三遍，五秒左右。网站是给你不在终端旁时用的。

浏览器里的声音和 CLI 不一样？

网站优先播放仓库提交的标准 MP3，只有播放失败时才回退到 Web Speech。CLI 把同一份英文式 respelling 交给自动检测到的系统 TTS 后端。

和普通发音词典有什么区别？

这本只收程序员日常会念的名字——Gemini 4 Neon、nginx、Pydantic、Knative、Cilium。Webster 没收，这里有，并且每条带 confidence 标签，有链接的附链接。

为什么 GIF 是 "jif"？我一直读 "gif"。

两种读法都真实存在。词典把创作者对纽约时报说的读法 ("jif"，Steve Wilhite，2013) 列为主读；硬 G 的 "gif" 读法使用明确的语音提示 "ghif"。say-it --alt GIF 听备选。SQL / JSON / char / regex 同款多读处理。

支持 Windows / Linux 吗？

支持。同一个 Bash CLI 会自动检测 macOS say、Linux espeak-ng/espeak 或 Windows PowerShell System.Speech。

怎么加一个缺失的项目？

提个 PR，在 data/pronunciations.tsv 加一行。列格式见 CONTRIBUTING.md。还有 置顶 issue 收集愿望清单。

来源 URL 是必填的吗？

不必。没有可附的链接就留空，confidence 标 community-consensus。宁可保守也不胡编。

为什么 CLI 在主读后还播 "or: ghif"？

多读法的词自带语境——你应该知道存在争议。可听的 "or: <alt>" 尾巴让你不盯终端也能感知。熟了之后 --solo 跳过即可。
