How to pronounce SQL Server

product contested

S Q L server /ˌɛs kjuː ˈɛl ˈsɜːrvər/ mp3
or: sequel server /ˈsiːkwəl ˈsɜːrvər/

SQL Server is most commonly pronounced "S Q L server" (/ˌɛs kjuː ˈɛl ˈsɜːrvər/). This is one of several readings in active use; the developer community hasn't converged on a single answer.

Both readings are current for Microsoft's database: letters ('ess-kyoo-ell server') and 'sequel server'. Microsoft itself uses both in its own talks, so neither is wrong — the letters are the safer default in an international room.

Alternate readings you might hear:

  • "sequel server" /ˈsiːkwəl ˈsɜːrvər/
