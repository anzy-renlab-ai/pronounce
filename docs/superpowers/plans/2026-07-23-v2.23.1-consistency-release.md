# v2.23.1 Consistency Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v2.23.1 with canonical homepage audio, accurate product facts, complete build guards, and incremental per-word OG rendering.

**Architecture:** Generate browser-facing slugs and alternate arrays from the Python source of truth. Route all dictionary playback through one request-token audio engine with MP3-first/Web-Speech-fallback behavior. Track OG currency with an atomic versioned manifest, then commit all generated site output before tagging the verified final SHA.

**Tech Stack:** Python 3 stdlib + Pillow, browser JavaScript/React globals, Node 20 built-in test runner/VM, Bash, GitHub Actions, Vercel.

_finish(req, status) {
