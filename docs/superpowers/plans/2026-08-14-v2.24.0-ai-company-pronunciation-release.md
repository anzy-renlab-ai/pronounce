# v2.24.0 AI Company Pronunciation Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish v2.24.0 with the Simile AI pronunciation corrected, three creator-verified AI company entries added, and every committed dictionary consumer regenerated and verified.

**Architecture:** Keep `data/pronunciations.tsv` as the only hand-edited pronunciation source. Guard the exact release rows and current product facts with repository tests, then use the existing generators for website pages, audio, OG cards, extension dictionaries, and dataset exports. Tag only the final commit that passes local release guards and remote GitHub/deployment checks.

**Tech Stack:** Bash, Python 3 stdlib + Pillow, Node.js tests/build scripts, macOS `say`, ffmpeg, Git, GitHub Actions, GitHub CLI.
